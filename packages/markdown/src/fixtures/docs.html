Streams

A stream is a value that arrives over time. Rivulet gives every stream the same three operations - map, filter and take - and each of them returns another stream rather than doing any work, so nothing runs until something reads.

Making one

The shortest stream is a list that has been told it is a stream:

import { from } from 'rivulet'

const numbers = from([1, 2, 3]).map((n) => n * 2)
for await (const n of numbers) console.log(n)

From Python the same three lines read almost the same way:

from rivulet import stream

numbers = stream([1, 2, 3]).map(lambda n: n * 2)
print(list(numbers))

Reading one

Reading is the only thing that does any work. A stream read twice is computed twice; keep the list if you need it again. The shell shows what happens when the reader is slow: 

$ rivulet run --slow-reader example.ts
waiting for the reader...

See backpressure for how a sink slows a stream down.
