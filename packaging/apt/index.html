Orden for apt

The apt repository of Orden, a markdown editor: Debian, Ubuntu and everything built on them, on x86_64 and arm64. Two suites: stable, the newest release, and unstable, the newest build of the unstable branch. Each holds the newest version alone; every release's .deb stays on its release page.

Add it

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @BASE@/orden-archive-keyring.asc | sudo tee /etc/apt/keyrings/orden.asc >/dev/null
sudo tee /etc/apt/sources.list.d/orden.sources >/dev/null <<'EOF'
Types: deb
URIs: @BASE@
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/orden.asc
EOF
sudo apt update
sudo apt install orden

For the unstable builds, Suites: unstable instead. On an apt older than 2.3, which reads no .sources file, the same in one line: 

echo "deb [signed-by=/etc/apt/keyrings/orden.asc] @BASE@ stable main" | sudo tee /etc/apt/sources.list.d/orden.list
